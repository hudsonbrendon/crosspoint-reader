Get started

Install InkPoint.

InkPoint runs on both the Xteink X3 and X4 from a single image — the device is detected automatically at boot. Pick the method that suits you.

My device

The same firmware is flashed for both; this only tailors the notes below.

METHOD 01 · RECOMMENDED

USB web flasher

Connect the reader with a USB-C cable, make sure it is awake on the home screen, then flash directly from this page:

Your browser doesn't support WebSerial — use Chrome or Edge on desktop. USB access was blocked. Reload and allow the serial port.

Requires Chrome or Edge on desktop. If the serial picker doesn't list your device, try another USB port or cable before assuming the device is locked.

METHOD 02

SD card

Works even when USB flashing isn't available:

  1. Download the latest firmware.bin from the latest release.
  2. Copy it to the root of the SD card (rename it however you like, e.g. inkpoint.bin).
  3. Insert the card, then on the device open Settings → Firmware update and pick the file.

Only flash firmware that includes SD-flashing or OTA update support, or you may lose the ability to update.

METHOD 03

Over-the-air

Already running InkPoint with Wi-Fi? Open Settings → Firmware update and the device pulls the latest release on its own.
